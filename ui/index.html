      Welcome to Plunge

      1. Pick a game you own. Plunge finds the engine and checks for built-in VR.
      2. Make it yours. Set your controls and comfort, then copy the brief to Claude Code or Codex to build the VR version.
      3. Press Play. Plunge installs it, and can remove it and restore your files any time.

      Games with anti-cheat are never modified, and builds never contain a game’s own files.
