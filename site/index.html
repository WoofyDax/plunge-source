Frequently asked questions

What does
Plunge do?
It makes the games you own playable in VR. An AI coding agent works out how, and Plunge installs the result into your own copy with one click.
Do I need
the games?
Yes. Plunge never includes or shares game files. It changes the copy you already own, and you can undo it.
Does every
game work?
No. Some games work well in VR and some do not, and results vary. Games with anti-cheat are left alone.
What does Play
actually do?
It installs the VR build, starts the game and checks that it really started. Uninstall puts every file back the way it was.
Can I
play together?
Only if the game or the build has online play. Plunge doesn't add multiplayer to a single-player game. Where it exists, press Host to get a short join code and send it to friends.
Can I make
my own?
Yes. Plunge hands a brief to the AI agent you already use, such as Claude Code or Codex. It builds the VR version and you can share it.
Is it
safe?
Plunge asks before it installs anything, backs up the files it changes, and checks community builds for dangerous files first.
What does it
cost?
Plunge is free. You pay for your own AI agent if you use one.
